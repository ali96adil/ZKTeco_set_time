# ZK CLOCK Manager v0.3 — Mac + iPhone (اختبار محلي)

**نسخة قراءة وأرشفة فقط.** هذا البرنامج لا يحتوي أي وظيفة لإضافة بصمات أو تعديلها داخل الجهاز أو في قاعدة SQLite؛ وهو منفصل عن مشروع M5 للساعة، ولا يعيد تفليش M5 أو يغيّر الوقت.

## الإضافات في v0.3

- دليل الموظفين (`/employees`) للبحث بالـID أو الاسم وعرض العدد وآخر حركة.
- صفحة مستقلة لكل موظف (`/employee?user=1723`) مع ملخص شهري، أول وآخر حركة، وحركات متقاربة خلال 10 ثوانٍ.
- تحديد شهر وقاعدة صباحية (افتراضياً 08:30) ومسائية (14:45) في الصفحة، **للعرض فقط**، دون حفظ أي تصحيح.
- الجمعة والسبت عطل أسبوعية افتراضية. اليوم بلا حركات يظهر «لا توجد حركات» وليس «غياب» أو «بصمة مفقودة».
- لا نفترض أن `punch=0/1` صالح لجميع الموظفين، والتصنيف يعتمد على توقيت الحركة فقط ولا يثبت طريقة التحقق.
- واجهات JSON محمية بنفس قفل الواجهة: `/api/employees` و`/api/employee?user=1723`.
- تشغيل اختياري للمزامنة الدورية **أمام المستخدم بالـTerminal** كل 30 دقيقة (أدنى فترة 10 دقائق). لا تعمل آلياً ما لم تشغّلها أنت، ولا تمسّ السجلات.
- واجهة الهاتف السابقة عبر HTTPS على الشبكة الخاصة ما زالت مدعومة. **ليست تطبيق iOS أصلياً** ولا تنشر إلى App Store.

## التثبيت على الماك (لا يمس الأرشيف)

النسخة السابقة v0.2 تعمل، لذلك أوقف نافذة السيرفر القديمة بزر `Control+C` أولاً. لا تحذف مجلد `local/` أو `.secrets/`.

1. نزّل الملف `zkclock_manager_v3.zip` وضعه داخل `Downloads` ثم نفّذ:

```bash
cd "$HOME/Downloads"
unzip -o zkclock_manager_v3.zip
bash "$HOME/Downloads/zkclock_manager_v3/install_on_mac.sh"
```

السكربت ينسخ ملفات Python فقط إلى `tools/` ويحفظ نسخ الكود القديم في `local/source_backups/`، ثم يشغّل **3 مجموعات اختبارات محلية** بلا أي اتصال بجهاز البصمة. لن يحذف `local/zkclock_manager.sqlite3`.

2. أنشئ نسخة إضافية من قاعدة الأرشيف (للاستعادة على الماك وليس داخل الجهاز):

```bash
cd "$HOME/zkteco-m5-lab/ZKTeco_set_time" || exit
python3 tools/zkclock_manager.py backup
python3 tools/zkclock_manager.py serve --port 8768
```

افتح `http://127.0.0.1:8768/` على الماك، ثم `دليل الموظفين` ثم `1723` أو `1733`. الأرشيف الحالي موجود؛ **لا حاجة لإعادة مزامنة الـ37,812 سجل قبل فتح الواجهة**.

3. عند الحاجة إلى قراءة مباشرة من الجهاز، استخدم Python الذي يعمل مع `pyzk`:

```bash
cd "$HOME/zkteco-m5-lab/ZKTeco_set_time" || exit
ZKPY="$PWD/local/.venv-pyzk/bin/python"
[ -x "$ZKPY" ] || ZKPY="$HOME/zkteco-clock/.venv/bin/python"
"$ZKPY" tools/zkclock_manager.py sync --host 10.1.65.2 --min-records 37812
```

أو افتح Terminal ثانياً وشغّل المزامنة كل 30 دقيقة (إيقاف بـ`Control+C`):

```bash
"$ZKPY" tools/zkclock_manager.py watch --host 10.1.65.2 --interval-minutes 30 --min-records 37812
```

المزامنة تحفظ فقط نسخة من السجلات الأصلية وتتحقق من عدم نقصان عدد السجلات المقروءة عن آخر قراءة؛ لا توجد عمليات `set_time` أو `clear_attendance` أو إدخال بصمات.

## الآيفون تجريبياً بدون App Store

المسار السابق `setup_phone_https.sh` محفوظ في الحزمة. شغّله على الماك لإعداد شهادة HTTPS خاصة بعنوان الماك على الشبكة، وراجع التعليمات الظاهرة. لا تنقل الملف `.key` للآيفون؛ انقل شهادة الـCA فقط واستخدم `Full Trust` عند الحاجة. لا تستخدم شبكة عامة أو تفتح منفذ الراوتر للإنترنت.

```bash
cd "$HOME/zkteco-m5-lab/ZKTeco_set_time" || exit
bash "$HOME/Downloads/zkclock_manager_v3/setup_phone_https.sh"
ZKPY="$PWD/local/.venv-pyzk/bin/python"
[ -x "$ZKPY" ] || ZKPY="$HOME/zkteco-clock/.venv/bin/python"
"$ZKPY" tools/zkclock_manager.py serve-phone \
  --bind MAC_LAN_IP --port 8769 \
  --cert .secrets/zkmanager-server.crt \
  --key .secrets/zkmanager-server.key --no-web-sync
```

استبدل `MAC_LAN_IP` بعنوان IP الخاص الذي يسرده سكربت الإعداد، ثم افتح `https://MAC_LAN_IP:8769/` من Safari. سيطلب اسم المستخدم `zkclock` وكلمة المرور التي تختارها في Terminal (12 حرفاً فأكثر). يمكن بعدها إضافته إلى الشاشة الرئيسية عبر Safari > Share > Add to Home Screen.

**مهم:** إذا الآيفون والماك على شبكة تمنع الاتصال بين الأجهزة، فلن تعمل الواجهة قبل معالجة صلاحيات الاتصال المحلية. حماية الشبكة وملف FileVault على الماك مهمان لأن قاعدة SQLite نفسها غير مشفّرة.

## الضوابط

- `local/` و`.secrets/` يجب أن يبقيا مستثنيين من Git؛ لا ترفع ملفات الموظفين أو المفاتيح.
- الجهاز iFace950 `Ver 6.60` ما زال **غير مؤكد** من جهة إدخال أو تعديل سجلات الحضور مباشرة. هذه النسخة لا تنفذ أي كتابة للجهاز.
- «حركات صباحية ومسائية» نتيجة زمنية استرشادية، وليست تقرير إثبات حضور أو شهادة إدارية أو مصدر لحركات اصطناعية.
- زر المزامنة في الواجهة يقرأ الجهاز؛ في وضع الآيفون يفضّل `--no-web-sync` حتى يكون التحديث بيد الماك فقط.
- ترحيل ملف SQLite السابق ليس بحاجة إلى إعادة بناء. يمكن الرجوع إلى كود v0.2 من نسخ `local/source_backups/` دون حذف أي سجل.
